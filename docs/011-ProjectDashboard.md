# ProjectDashboard

### Project Dashboard

1. left pane \- Project Tree, include project name and version, a toggle to show Documents in the tree
2. right pane \- control loader for ProjectEdit, Component Document Tab

```
+--------------+--------------------------------------------------+
|  LEFT PANE       |                 MAIN CONTENT                 |
|  (Width: 25%)    |                 (Width: 75%)                 |
|                  |                                              |
|  - Project Tree  |              [Component loader]              |
|  - Filters       |                                              |
|  - Settings      |                                              |
|                  |                                              |
+------------------|                                              |
| Add Component    |                                              |
+-----------------------------------------------------------------+
```

**Components**

1. Project Tree \- tree ui to show a the project hierarchy
2. Project Edit \- component to edit the project properties like Title and Description
3. Component edit \- component to edit the like Name and Description
4. Document Editor \- HTML Document editor used for editing markup\.
