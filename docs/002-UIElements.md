# UIElements

### Login

Single form page for user name and password entry and account recovery\.

### Authenticated Master Template

1. Top Nav
2.  Component loader
   
     1. left pane to loads page views
     2. right pane for AI Chat bot

### **Buttons**

All buttons should have an icon\.

1. large buttons must have text
2. small buttons just an icon

### Grids

1. columns are sortable
2. pagination enabled at the bottom of the grid
3. last column as action buttons: edit, delete

### Confirmation Modal

1. iill have  custom Title
2. body will have a confirmation message
3. Yes, No

### Modals

1. Will have  a custom Title
2. body can contain injected components that can be wired to the Ok or Cancel buttons\.
3. buttons can have custom labels for Ok, Cancel

**Chatbot**

1. integrated as an iframe to insert third party chat bot systems
