# Project Vision

## **Project Vision**

RGI is a Requirements Gathering System with the use of AI to assist users in capturing software requirements to generate software\. Users organize requirements as a component tree\. Components can contain many documents\. A Project can be exported so other AI agents can later consume them to generate software\.

### Project

1. can be used as templates and can be selected to seed new projects
2. must support versioning
3. can be exported to Git, PDF, or JSON

### Component

1. can contain multiple documents
2. can be of type group or component
   
     1. group \- used to group components together in the Project Tree
     2. component \- can store many document
