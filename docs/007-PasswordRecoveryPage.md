# PasswordRecoveryPage

### Password Recovery

To reset your password, please follow these instructions: click the 'Forgot Password' link on the login screen and enter your registered email address\. The user will receive a secure link via email to create a new password and regain access to your account\.   
  
The link will expire based on the siteConfig\.  
  
When the user clicks on the link,  they can set a new password and get back into your account\.
